## 요구 사항

### 1. 과제 진행 요구 사항
* 미션은 **자동차 경주** 저장소를 포크하고 클론하는 것으로 시작한다.
* 기능을 구현하기 전 **`README.md`에 구현할 기능 목록을 정리해 추가**한다.
* Git의 커밋 단위는 앞 단계에서 정리한 기능 목록 단위로 추가하며, **AngularJS Git Commit Message Conventions**을 참고해 커밋 메시지를 작성한다.
* 자세한 과제 진행 방법은 프리코스 진행 가이드 문서를 참고한다.

### 2. 기능 요구 사항 (초간단 자동차 경주 게임)
* **기능 목표**
    * 주어진 횟수 동안 n대의 자동차가 전진 또는 멈추는 경주 게임을 구현한다.
* **세부 사항**
    * 각 자동차에 이름을 부여할 수 있으며, 전진 시 자동차 이름을 같이 출력한다.
    * 자동차 이름은 쉼표(`,`)를 기준으로 구분하며 **5자 이하**만 가능하다.
    * 사용자는 **이동 횟수**를 입력할 수 있어야 한다.
    * 전진 조건: 0에서 9 사이의 무작위 값이 **4 이상**일 경우이다.
    * 우승자 선정: 경주 완료 후 가장 많이 전진한 자동차를 우승자로 결정하며, **공동 우승**이 가능하다. 우승자가 여러 명일 경우 쉼표(`,`)로 구분한다.
* **예외 처리**
    * 사용자가 잘못된 값을 입력할 경우 **`IllegalArgumentException`**을 발생시킨 후 애플리케이션이 종료되어야 한다.
* **입출력 요구 사항**
    * **입력:** 경주할 자동차 이름 (쉼표 기준으로 구분), 시도할 횟수
    * **출력:** 차수별 실행 결과, 최종 우승자 안내 문구
    * **실행 결과 예시**
    ```        
    경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
    pobi,woni,jun
    시도할 횟수는 몇 회인가요?
    5
    
    실행 결과
    pobi : -
    woni :
    jun : -
    
    pobi : --
    woni : -
    jun : --
    
    pobi : ---
    woni : --
    jun : ---
    
    pobi : ----
    woni : ---
    jun : ----
    
    pobi : -----
    woni : ----
    jun : -----
    
    최종 우승자 : pobi, jun
    ```

### 3. 프로그래밍 요구 사항
* **JDK 21** 버전에서 실행 가능해야 한다.
* 프로그램 실행의 시작점은 **`Application`의 `main()`**이다.
* `build.gradle` 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
* 프로그램 종료 시 `System.exit()`을 호출하지 않는다.
* **자바 코드 컨벤션**을 지키면서 프로그래밍한다. (Google Java Style Guide 원칙)
* `indent(들여쓰기) depth`를 **2까지만 허용**한다.
* **3항 연산자를 쓰지 않는다.**
* 함수(또는 메서드)가 **한 가지 일만 하도록** 최대한 작게 만들어라.
* **JUnit 5와 AssertJ**를 이용하여 기능 목록이 정상적으로 작동하는지 **테스트 코드로 확인**한다.
* `camp.nextstep.edu.missionutils.Randoms` 및 `Console` API를 사용하여 구현해야 한다.

## 구현할 기능 목록 (현재 코드 기반 재구성)

캡슐화를 최대한 지키며 클래스 구성을 책임에 맞춰 나눴고 SRP를 최대한 지켜 각각의 기능을 해당 책임에 맞는 클래스에 맞춰 분배했습니다.

* **실행 흐름제어**: `Controller`
    * `run메소드`
    * `checkCount메소드`
    * `countMove메소드`: 정해진 횟수만큼 `Cars.raceOnce 메소드`를 반복 호출하고, 매 차수 결과를 출력한다.

* **일급 콜렉션**: `Cars`
    * 생성자: 입력 문자열을 받아 `CarNamesParse`를 통해 `List<Car>`를 초기화하고 저장한다.
    * `raceOnce메소드`: 콜렉션 내 모든 `Car`에게 `Car.move()`를 호출하고 받은 문자열을 이어 붙여 **라운드 결과 문자열을 반환**한다.
    * `findWinner메소드`
    * `findMaxMove메소드`: 콜렉션 내 모든 `Car` 중 최대 이동 횟수를 찾는다.

* **개별 도메인 객체**: `Car`
    * 생성자
    * `move()`
    * `makeComment메소드`: 자신의 이름과 위치를 이용하여 **라운드 출력 포맷 문자열을 생성**하여 반환한다.
    * `getMoveCount메소드`
    * `getCarName메소드`

* **문자열 파싱 및 유효성 검사**: `CarNamesParse` (Static 유틸리티 클래스)
    * `parse메소드`: 입력 문자열을 파싱하고 유효성 검사 후 `Car` 객체의 `ArrayList`를 생성하여 반환한다.
    * `splitCarNames메소드`
    * `isEmpty메소드`: 자동차 이름이 입력되지 않은 경우 예외 처리한다.
    * `checkCarNames메소드`

* **IO 관련 로직**: `IOConsole` (Static 유틸리티 클래스)
    * `inputCars메소드`
    * `inputCount메소드`
    * `roundResultPrint메소드`
    * `printWinner메소드`
    * `makeComment메소드`: 우승자 이름 목록을 쉼표로 연결하여 **출력용 문자열을 생성**하여 반환한다.

* **예외처리 Test 관련 로직**: `CarNamesParseTest`, `ControllerTest`

## 테스트 실행 가이드

미션 제출 전, 구현한 기능이 요구 사항을 모두 만족하는지 다음 명령어로 확인한다.

1. **Java 버전 확인 (JDK 21):**
    ```terminal
    java -version
    ```
2.  **테스트 실행:**
    * Mac 또는 Linux:
        ```bash
        ./gradlew clean test
        ```
    * Windows:
        ```bash
        gradlew.bat clean test //또는
        .\gradlew.bat clean test
        ```

모든 테스트 통과 시 다음과 같은 메시지가 출력됩니다.

```
BUILD SUCCESSFUL in 0s 
```
